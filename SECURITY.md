# Security

This demonstration binds to localhost and is not configured as a multi-user hosted service. Keep it local unless you add authentication, authorization, deployment hardening and an appropriate data policy. Model files are trusted application artifacts; never load untrusted pickle or joblib objects.

Do not post credentials, real maintenance notes, equipment identifiers, source workbooks or populated databases in public issues. For a security issue, contact the repository owner privately or use GitHub private vulnerability reporting if it has been enabled. This package does not claim that reporting has already been enabled on an unpublished repository.

The public package excludes private project data and was checked for common credential patterns, original identifiers, local paths and spreadsheet metadata. These checks are not a comprehensive security audit.
