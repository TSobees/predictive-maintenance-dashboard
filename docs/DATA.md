# Data guide

All public assets, observations and events are independently generated by `tools/generate_demo.py`. It reads no workplace register, source workbook or remote dataset. The seed and rules are public. All stations are Demo Station A–D and asset IDs begin DEMO-. Code, generated data and demo models use the MIT license.

## CSV-only public package

The default source is `maintenance_app/data/demo/`, containing `assets.csv`, `events.csv` and `observations.csv`. Analytics reads the register and events using the same validation and episode-counting rules as local Excel inputs. All three files are included in the source fingerprint and change detection. Model training uses the same generated CSVs. No Excel file is required.

`analytics_workbook.xlsx` and its duplicate `training_dataset.xlsx` are excluded from GitHub and the release ZIP. Excel files are ignored by Git. Their local copies may remain on the owner's computer and are not used by the public app's default source. The dataset download supplies the fictional CSV inputs and provenance as a ZIP containing no Excel file.

## Optional local Excel input

The source form accepts an existing `.xlsx` inside the project folder, or an `events.csv` alongside the other two CSV bundle members. A local workbook requires Equipments and Breakdowns sheets, equipment IDs, station and equipment names, maintenance categories and start timestamps. Save and recalculate formulas before refreshing. No local Excel file is automatically committed or uploaded.

## Definitions

Breakdown means a simulated complete operational stop. Linked work orders sharing the same per-equipment failure ID count as one episode at its earliest timestamp. Follow-up work still counts in maintenance-category activity. Station rates divide breakdown counts by registered assets, including zero-event assets, and are not adjusted for operating exposure. Recorded event downtime can overlap and does not establish plant outage time, availability or MTBF.

## Refresh and storage

The page checks saved changes every minute while visible and on manual refresh. A partial save or invalid source retains the last successful snapshot with a warning. Source selections are confined to the project and saved in ignored `data/analytics_config.json`. Updating chart data does not retrain model weights. User readings, schedules, completions and notes stay in ignored local SQLite storage. Keep real data under ignored `local_data/` and review staged files before pushing.

## Reproduce

Run `python tools/generate_demo.py`, followed by `python tools/train_demo.py`. No Excel file is read or written. Tests check deterministic CSV regeneration, register/event reconciliation, source fingerprints, refresh behavior and causal model features.
