# Demo walkthrough

1. Start the app and review the public-demonstration banner. Overview scores refer to bundled historical observations.
2. In Breakdown analytics, choose Top 20, switch to recorded downtime, filter Demo Station B, and click a machine. Export the filtered CSV. Reset the filters to compare rates across all stations.
3. In Forecast & cycle, select DEMO-A-001 and compare 7-, 14- and 30-day window risks. Read the historical/synthetic warning and inspect score contributions. Past breakdown spacing is descriptive, not a service interval.
4. In Predict & upload, load a historical example and calculate a replay. Switch to new-observation mode only when entering a later timestamp with supplied readings.
5. In Maintenance due, plan an example inspection with an approved date in the past. Confirm it is overdue, record a completion, and check that only the specific task advances. Hours-based examples require measured cumulative meters.
6. Save edits to the synthetic CSV bundle and choose Refresh data, or track a locally supplied Excel workbook in Data source. Observe that charts update while fitted model weights do not.

Before recording a walkthrough video or sharing screenshots, use only the bundled demo data and hide local filesystem details. All included screenshots use that data. Demo plans or new observations entered during a walkthrough are local and are not distributed with the repository.
